# KamCam

KamCam v1 binary distribution. This repository intentionally contains no source code.

Download the Android APK and Windows application from the private GitHub Releases page when available. Only signed/packaged application files belong in release assets; source code is not published here.

The Android app supports Android 5.0 (API 21) and later. The Windows client requires Windows 11 for KamCam's native virtual cameras. Both sides must use the same protocol version.

The repository is private. Access to the app files still allows recipients to copy them; the proprietary license governs use but cannot technically prevent copying.
